# Text

The Text component renders a paragraph with predefined typography defaults. It includes readable font size, line height, and vertical spacing optimized for email readability.

## Usage

```blade
<x-envelop::text>
  This is a paragraph of text in your email.
</x-envelop::text>
```

## Props

| Prop | Type | Required | Default | Description |
|------|------|----------|---------|-------------|
| `class` | `string` | `No` | `''` | Atomic CSS utility classes |
