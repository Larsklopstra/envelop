# Hr

The Hr component renders a horizontal divider with consistent styling across email clients. The default style is a subtle 1px top border in light gray.

## Usage

```blade
<x-envelop::text>Content above</x-envelop::text>

<x-envelop::hr />

<x-envelop::text>Content below</x-envelop::text>
```

## Props

| Prop | Type | Required | Default | Description |
|------|------|----------|---------|-------------|
| `class` | `string` | `No` | `''` | Atomic CSS utility classes |
